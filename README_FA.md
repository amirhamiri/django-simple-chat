# چت عمومی ساده با Django

## اجرا در ویندوز
1. Python 3.10 یا جدیدتر را نصب کنید.
2. این پوشه را استخراج کنید.
3. فایل `run_windows.bat` را دوبار کلیک کنید.
4. مرورگر به آدرس http://127.0.0.1:8000 باز می‌شود.

در اجرای اول، فایل batch محیط مجازی می‌سازد، Django را نصب می‌کند و دیتابیس را آماده می‌کند.
برای توقف سرور، پنجره ترمینال را ببندید یا Ctrl+C بزنید.

## اجرا در macOS / Linux
در ترمینال داخل پوشه پروژه:
```bash
chmod +x run_unix.sh
./run_unix.sh
```

## ویژگی‌ها
- بدون ثبت‌نام و احراز هویت
- ارسال پیام با فرم HTML
- ذخیره پیام‌ها در SQLite
- نمایش ۱۰۰ پیام آخر
- بدون WebSocket؛ برای دیدن پیام‌های تازه، صفحه را تازه‌سازی کنید.

## نکته
آدرس 127.0.0.1 فقط روی همان کامپیوتر در دسترس است. برای استفاده دیگران باید پروژه را روی یک سرور اینترنتی مستقر کنید.
این نمونه برای شروع و یادگیری است و پیش از انتشار عمومی، به محدودیت نرخ ارسال، مدیریت پیام‌ها و محافظت ضد هرزنامه نیاز دارد.
